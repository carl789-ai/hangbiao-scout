# 原版流程对照与本次修正

依据为用户提供的1.4.2可读代码、七份原始提示词、本地还原版界面与4175利润工具。保留用户认可的工作台框架与商品资料页，不再另起产品逻辑。

| 流程 | 对应实现 | 本次行为 |
|---|---|---|
| 导入后仅采集 | 工作台“仅采集” | 不调用模型，原字段和所有来源保留 |
| 导入数据仅AI | “仅分析导入数据” | 选择原表字段，每批5词，全部任务范围，结果逐词保存 |
| 采集并AI | “采集后AI分析” | 每个采集批次保存后分析，成功记录不重做 |
| 关键词模型输入 | 原系统约束＋综合/蓝海/PPC三模板 | 原始字段和采集指标一起发送，保留自定义模板 |
| 关键词模型输出 | 18字段综合分析 / 蓝海 / PPC | 检查ID与关键词，拒绝错位、重复、非法分数和缺少必填项；返回部分成功时保存成功项 |
| 商品研判 | 原逐商品模板＋十维评分标准 | 单商品独立分析、ASIN核对、程序按原权重重算总分、保存结果 |
| 市场分析 | 原市场与细类机会模板 | 当前商品样本输入，缺失集中度与关键词数据保持缺失 |
| 关键词打开 | 当前站点搜索链接 | 点击词直接新开Amazon，不弹JSON；“资料与分析”单独展开 |
| 数据展示 | 表格＋结构化详情 | 指标、原表字段、来源、模型评分与理由对应同一记录 |
| 利润核算 | 4175项目同源纯计算模块 | 工具窗口，CNY采购/头程、USD销售/FBA、成本拆分、保本价、售价情景、包装优化 |
| 异常恢复 | 逐词持久化＋暂停 | 失败词网页链接、导出已完成、任务备份、继续未完成项 |

FBA费表来自4175现有2026美国非服装费表，包含明确周期选择；它不是实时查询。其他站点与周期使用手动FBA覆盖。头程单价与汇率由使用者填写，不发布4175公司配置或私有记录。

仍未接入原供应商云端的商品库、店铺库、BSR销量估算等能力；本轮不以空数据或模拟数替代。该范围写在开发文档，操作界面以实际可用工具和具体恢复动作呈现。
