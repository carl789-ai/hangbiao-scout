# 技术说明

## 结构与存储

Chrome MV3 service worker处理启动、暂停、临时防休眠和offscreen生命周期；offscreen文档负责fetch、DOMParser和逐条写入IndexedDB。工作台不是采集执行器，关闭工作台不应丢失已保存结果；Agent连接则需要保持工作台页打开。

任务、唯一词、原始行使用独立store。原始行与唯一词在同一事务导入；成功结果在单词事务中保存。只允许一个运行任务；offscreen单例和后台串行门防止重复执行器。Chrome启动/每分钟watchdog发现执行器消失时，将任务标记暂停；继续前重置遗留working项。已done结果不能被迟到失败覆盖。

不把所有关键词的完整HTML保留在内存。每批最多5个请求，单响应上限12MB，网络30秒超时；DOM仅存活于一次解析；保存提取的结构数据后丢弃文本。Amazon评分和评论共用一个区域，评论选择器仅接受带明确 `ratings/reviews` 数字的标签，不把星级误作评论数；未知评论不计入蓝海值，全部缺失时比率为null。结果表只渲染100行，筛选扫描元数据，原始行按250条读取。XLSX逐文件解析、分块保存。

## 内存限制的实际含义

Chrome没有一个适用于所有设备和版本的统一JS堆上限。`--max-old-space-size`是Node/V8相关参数，不能作为给客户提升Chrome采集容量的通用教程。无限存储权限也不等于无限内存或无限磁盘。

每500个请求关闭并重建offscreen解析环境；若performance.memory可用且当前JS堆达到256MB则提前轮换。该API不是所有上下文都提供，故请求计数轮换始终存在。256MB是触发阈值，不是整个Chrome进程、GPU、缓存或任务总内存的硬上限。其他标签占用不能由插件约束。

文件导出优先File System Access逐段写盘；不支持时使用有192MB上限的Blob回退。恢复大备份仍需解析JSON，备份文件超过384MB时拒绝整包恢复；应在原Chrome继续或由agent分批迁移。大任务建议接电、少开无关重页面、保留充足磁盘，每次暂停后下载备份。

## Amazon异常

搜索页返回异常时，记录具体关键词、URL与错误类型。界面给出检查网页、导出已完成及继续未完成的操作；不会将失败算作成功。
403、429、503、验证码、无法确认的搜索结构均暂停；不自动轮换代理、不绕过验证。网络断连不写成正常0值。专题跳转有明确outcome且指标null。

## 自定义API

跨域权限只对用户授权的中转站origin申请，支持HTTP/HTTPS。仅发送到用户填写的Chat Completions端点，Authorization为Bearer；不跟随重定向，不把Key带到重定向站点。密钥留在chrome.storage.local，不进入任务备份；普通密码框不是加密保险库。

## Agent

Node本机网关仅绑定127.0.0.1，随机Bearer令牌鉴权，拒绝普通网页Origin。端点仅接受列出的任务动作，不提供任意代码执行。插件主动轮询，不开放外部网页直接控制。网关命令与响应只在进程内存保留1小时、最多100条，重启后消失；采集数据依然在插件IndexedDB。

命令被领取后不会自动再次派发，避免创建重复任务；若浏览器在领取后中断，agent应查询任务实际状态，确认后重新发命令。大导出通过界面写盘或分页读取，Agent单次导出48MB上限。日志不输出Key，发布包不包含任何个人采集数据或配置。

## 原版AI任务链路

复用原版系统约束、关键词综合/蓝海/PPC、逐商品、十维评分及市场机会七份提示词。关键字任务使用五词批次、稳定ID与关键词双重匹配，JSON结构校验、逐词保存、缺失项续跑。原表字段通过[taskId,key]索引按当前批读取，所有来源分别保留，不限制到前20条。AI与采集数据分别保存，HTTP中转站请求继续使用用户配置。任务备份不包含密钥；模型名称与分析结果随记录保留。

IndexedDB版本3增加原行关键词及AI状态计数索引，沿用既有库名与存储。升级不清空旧任务。其他工作台阻止升级时提示关闭其他标签并刷新。

利润纯计算模块从用户4175项目移植，FBA静态费表、头程与售价情景共享同一计算口径；不含其业务记录、API、公司费率配置。详见流程对照。
