# 2.0.0-beta.1 验收记录

日期：2026-10-18。定位：可公开源码及下载的候选beta，尚不是所有平台验收完成的正式版。

## 已通过

- Node自动测试：16项，覆盖解析、阈值/去重/广告排除、未知评论标记、狗页/验证码、HTTP403/429/503、CSV保留与公式防护、利润、数据库事务回滚、单任务运行、成功不可被失败覆盖、备份恢复与续采、Agent令牌鉴权、真实本机HTTP兼容模型请求、独立Agent适配器落盘续采、XLSX共享字符串和空列导入、文件大小限制。
- Mac日常Chrome网页模块：使用真实IndexedDB导入20,000个唯一词和20,001条原始行；模拟5,000成功后5项失败，显示15,000待采集；导出CSV保留5,001原始行；JSON恢复保留5,000成功；续采只调用剩余15,000项；最终20,000成功，无成功词重采。共40次500请求逻辑分段。此项是模拟响应，未向Amazon新发20,000次请求。
- 独立HTML：5,001行导出，51页、最后一页1行；重复词2行，来源筛选后1行；空结果禁用跳转。源数据通过textContent显示，JSON转义小于号。
- UI：1440×900桌面、390×844小屏、960×900中间宽度实际渲染；检查空态、暂停与失败态、筛选、分页、设置输入。无整页横向滚动。主内容15px、输入16px。修复了切换导航意外滚走标题、侧栏次要文案换行和导出按钮字号偏小三个问题。
- 色彩：使用WCAG AA作为APCA不可用时的替代测量；正文12.55:1，次要文字5.57:1，主按钮7.23:1，异常提示7.50:1。均通过对应正文AA阈值。
- 独立源码，无原厂商bundle/私有账号、API配置、个人数据库或真实采集结果进入发布包；fflate许可随包。

## 尚未完成的真实环境验收

- 新插件未实际加载到当前Chrome扩展宿主。日常浏览器工具不支持Extensions.loadUnpacked，因此没有把网页模块测试冒称MV3安装测试。
- offscreen后台生命周期、扩展宿主跨域权限/会话Cookie、防休眠、系统重启恢复和真实安装后文件保存需在安装插件后复核。
- Windows原生Chrome安装、长期采集、系统休眠恢复未在本机实测。Mac/Windows包共用相同核心；双包不等于两套操作系统均已实测。
- 本次未用用户中转站或付费模型试跑；HTTP本机测试只验证请求及响应结构，不代表所有中转商兼容。
- 新版尚未完成全量真实Amazon采集。新增小样本网页检查出现浏览器工具超时，未取得可用于“新版已实采通过”的证据；旧版两次采集成功不作为新版网络路径已通过的证明。

## 安装后验收清单

1. 两词采集：查看请求是否带日常会话、指标是否可读。
2. 暂停/继续、关闭工作台后后台执行、关闭Chrome再打开后恢复。
3. 已采集HTML/CSV、未完成清单、JSON备份与恢复。
4. 500请求offscreen轮换是否继续，且没有双执行器。
5. 自己HTTP或HTTPS中转站的地址授权、取消、超时及结果下载。
6. 在Windows和Mac各自检查以上流程后，才提升为稳定版。

已知边界和版本差异见技术说明、使用教程及CHANGELOG。旧版尚未恢复的供应商服务端能力不在本次“功能一致”承诺内。
