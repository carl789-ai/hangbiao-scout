# 使用教程

## 1. 建立任务

点击“新建采集任务”，填写名称并选择Amazon站点。导入一份或多份XLSX、CSV、TSV或TXT，也可直接每行输入一个词。

ABA表头支持“搜索词”“搜索关键词”“关键词”“Search Term”“Keyword”等。XLSX会读取包含关键词列的工作表，原字段以原值字符串保留，不重新计算Excel公式。重复表头请先改为不同列名。单文件限35MB，工作表XML限64MB、总展开128MB；大文件请先拆分。

同一任务、同一站点中，关键词去除两端空格并忽略大小写后去重请求；重复原始行、八份/多份来源字段保留。界面按唯一词显示，HTML/CSV按原始行导出。

## 2. 开始与进度

先用少量词检查网页与网络，再开始大任务。默认3条并发，每批间隔1200ms；可改1/3/5条并发和500–30000ms间隔，下次开始生效。一次仅运行一个采集任务。

- **已采集**：成功解析搜索页或确认专题跳转的唯一词数。
- **待采集**：总数减已采集，包含等待、正在请求和待重试。
- **待重试**：曾经失败的未完成词，是待采集的子集，不与待采集相加。
- **搜索 / 跳转**：专题或店铺跳转没有搜索指标，以“—”显示，不填零。

例：总20,000词，成功5,000、失败5词时，已采集5,000，待采集15,000，待重试5。每条成功后立即保存，不依赖整批完成再落盘。界面每4秒刷新，刚成功的请求可能要几秒才显示。

## 3. 失败后先保存，再恢复

Amazon可能返回验证码、403/429/503、狗页或未知结构。插件会记录失败原因、保存当前结果并暂停，不持续撞请求，不自动更换VPN节点。

1. “下载已采集HTML”或CSV，立即保存可用结果。
2. “备份整个任务”，保存JSON；它包含已采集结果、未完成词、原始行和来源，不包含AI密钥。
3. “下载未完成清单”可另开任务采集剩余词，但会成为独立任务。需要延续同一进度时请使用继续按钮或JSON恢复。
4. 在日常Chrome手动打开Amazon和同一关键词搜索，检查网页恢复。不要自动绕验证码；仅等网页恢复后点击“继续未完成项”。
5. 继续只请求未完成项，包括失败项；成功结果不会被重试覆盖。

刷新工作台不会清空任务。Chrome退出或执行器崩溃后，重开工作台，任务会暂停等待继续；已经完成的请求保留。极端崩溃发生在落盘前时，最后正在处理的少量词可能需要重新请求。

## 4. 导出与换电脑

HTML：独立查看、关键词与来源/蓝海筛选、每页100条、页码跳转、展开原始字段。保留已采集词对应的所有原始重复行。
CSV：保留来源和原表字段；为防电子表格把用户数据解释成公式，以`= + - @`等起始的文本加前导单引号；完整原值仍在JSON备份和HTML原字段中。
JSON：整个任务的迁移备份。换电脑后点“恢复任务备份”，恢复后再继续。HTML/CSV不能当作完整断点备份。

导出优先使用Chrome直接写文件，按用户所选位置保存。浏览器不支持直接保存时回退普通下载；回退文件上限192MB。不要在正在导入文件时退出工作台；导入中断时已保存部分可导出，剩余文件另建任务导入。

## 5. 统计口径

蓝海值=当前搜索首页非广告商品按ASIN去重后，已读取到且评论数≤100的商品数。无法读取评论的商品不计入蓝海值，但会计入“首页商品数”并显示在“未知评论商品数”中。若评论数全部缺失，比率显示“—”而不是伪造0%或100%；如果仅部分缺失，缺失项仍包含在首页商品分母中。

Amazon搜索页同时标注星级与评论数；解析时只读取明确含 ratings/reviews 的数字标签，不会把“4.8 out of 5 stars”读成4.8条评论。平均价格/评论/评分只以已读到该字段的商品计算。购买标签支持1.5K+和1,000+等格式的解析；缺失购买标签以0参与合计，显示的是可读标签的合计，不是精确月销。新版与旧版数字可能不同。

搜索结果数仅在读取到页面明示数量时提供；未支持的语言格式显示缺失。蓝海只描述当前搜索首页样本，不等于完整市场竞争程度、利润或专利安全。

## 6. 商品、利润与AI

商品资料可读取已打开的Amazon搜索页；点关键词可查看当次指标和商品样本。利润用自己的售价、订单构成、佣金、退货率、FBA费用等计算，先统一币种。

AI在“设置与帮助”填写Base URL、模型标识和API Key。Base URL通常填写到`/v1`，也支持自定义完整`/chat/completions`路径。HTTP和HTTPS均可，浏览器会就该地址请求连接权限。HTTP明文传输，请只使用你信任的网络。配置不自动测试或调用模型。

在AI研判页选模板、编辑要求，粘贴数据或载入当前筛选前20条，再点“开始分析”。该操作会把输入发送至你配置的服务并可能计费。采集与AI完全分开；未点击分析不会调用。结果作为待核查建议，未知指标不补造。

## beta.1 的错误旧结果

升级不会把错误评论数凭空修算，也不会自动覆盖已有成功记录。旧解析结果显示“旧版 · 待核验”，导出亦有提示。先备份，再点“建立重采副本”，原关键词、重复行和来源都会复制到新任务；点击开始后重新采集。旧任务完整保留可追溯。
