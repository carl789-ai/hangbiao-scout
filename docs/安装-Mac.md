# Mac 安装教程

适用于 Google Chrome 116及以上。插件为纯浏览器扩展，Intel 与 Apple Silicon 使用同一份代码；无需运行 .command、安装 Node 或修改系统安全设置。

1. 解压 `Hangbiao-Scout-2.0.0-beta.3-Mac.zip`，把文件夹放到长期保留的位置，例如“文稿/航标选品”。不要放在之后会清理的临时目录。
2. 打开 Google Chrome，在地址栏输入 `chrome://extensions`。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择包内 **extension** 文件夹（里面有 manifest.json）。不要选上一级完整发布文件夹。
5. 工具栏点击拼图，固定“航标选品”，点击其图标打开工作台。
6. 打开 Amazon 网站，确认日常网络、语言和登录状态正常。建立一个小任务测试后再导入大批量。

可以尝试把 extension 文件夹直接拖到已经打开开发者模式的扩展页；如果拖入无反应，用“加载已解压的扩展程序”。ZIP不是CRX，不需要运行安装脚本。

更新：先暂停、备份整个任务。用新文件替换原安装文件夹内容，回到扩展页点重新加载。不要先卸载：卸载会删除该扩展的本地数据库。移动目录或更换Chrome配置文件可能产生新的扩展身份，应导入JSON备份恢复。

长任务：保持Mac接电、Chrome运行、网络稳定。采集期间插件临时请求阻止系统空闲休眠，但不能阻止合盖休眠、手动休眠或退出浏览器。屏幕熄灭可以；合盖仍可能中断。不要通过增大V8堆上限解决普通大任务。

当前版本的浏览器模块在Mac日常Chrome进行了界面验收；真实安装后的offscreen与跨域权限行为仍需按包内验收清单确认。Windows未在本机原生系统实测，详见验收记录。

## 从 beta.1 升级

先在旧插件点击“备份整个任务”并确认 JSON 已保存。保留旧安装位置，将新版 `extension` 内的文件覆盖到旧 `extension` 文件夹中，再到扩展管理页点击航标的“重新加载”。不要先卸载或清理浏览器数据；改用另一安装路径可能产生另一个扩展ID和空数据库。升级后界面显示 beta.3，文件夹名仍含 beta.1 不影响使用。

旧版评论与蓝海指标存在解析错误。切换回旧任务会显示待核验提示，点击“建立重采副本”，再点击“开始采集”。原任务和原始行仍在，副本从当前 Amazon 页面重新获取数据。已有正确新版任务的“继续”仍只请求未完成项。
