# Windows 安装教程

适用于 Google Chrome 116及以上。发布包使用与Mac相同的MV3插件核心，无需.exe、Node或Python。当前未在真实Windows系统进行安装实测，先作为beta试用。

1. 右键 `Hangbiao-Scout-2.0.0-beta.1-Windows.zip`，选择“全部解压”。不要直接在压缩文件预览窗口内安装。
2. 把解压目录放到长期保留的位置，例如“文档/航标选品”。
3. 在Chrome地址栏打开 `chrome://extensions`，打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择目录内 **extension** 文件夹。
5. 点击Chrome工具栏的拼图，固定“航标选品”，点击图标打开工作台。
6. 打开Amazon，确认网页正常。先采几个词，再导入大批量任务。

也可把extension文件夹拖到开启开发者模式的扩展页。ZIP文件不能直接作为商店扩展安装。本包不是签名CRX，不承诺双击即可自动安装；公司管理的浏览器若禁用了开发者扩展，需要管理员的安装策略。

更新：暂停并下载JSON备份；替换原安装目录里的插件文件；到扩展管理页点重新加载。不要先卸载，卸载会删除本地任务数据。换电脑后请安装插件，再恢复JSON备份。

长任务保持Chrome运行、电脑接电且联网。采集期间临时请求防止空闲休眠，不修改Windows电源全局设置；手动睡眠、关机、合盖、系统更新重启仍会中断。恢复浏览器后继续未完成项即可。

验收：实际确认安装、创建两词任务、权限请求、后台采集、暂停/继续、下载、恢复、HTTP中转站配置，再用于客户任务。不要把Mac测试结果表述为Windows实测通过。
