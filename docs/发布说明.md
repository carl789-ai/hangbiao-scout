航标选品 2.0.0-beta.2：修复 beta.1 的评论解析与页面读取错误。

- 修复将“4.8 星”误当成“4.8 条评论”导致蓝海比率普遍 100% 的问题。未知评论保持缺失，不归入低评论商品。
- 修复 Service Worker 动态 import 报错；多个 Amazon 标签并存时选择搜索页。
- 旧结果增加待核验提示和导出标记，新增“建立重采副本”，原始任务、重复原始行和来源都保留。旧版错误指标不能直接修算，需重新采集。
- Mac/Windows ZIP 解压后加载 extension 文件夹，普通用户不需要 Node/Python。已有用户请先备份任务，再将新版 extension 的内容覆盖到原安装目录并重新加载，避免卸载导致数据丢失。详见包内安装教程。
- 支持自定义 HTTP/HTTPS 中转站；采集不调用 AI。本次没有调用付费模型。

2026-10-27 已在 Mac 日常 Chrome 的实际已安装 MV3 扩展中完成三词真实采集，工作台分别显示蓝海比率 22.9%、8.3%、0%；页面读取显示正确的 8,738 条评论和 4.4 星。原 1,825 词任务、180 条旧成功记录在升级后保留并标记待核验。网页小样本和当天页面有关，不保证以后数值不变。

此前的 20,000 词断点、导出、备份恢复及仅续采未完成项验收使用模拟响应，不能当成新版实采两万词。Windows 原生 Chrome、长期批量任务、500 请求 offscreen 实际轮换和系统休眠恢复尚未完成宿主实测；实际安装后的 HTML/CSV 文件保存尚未取得落盘验证。本版本继续为候选 beta。完整边界见 docs/验收记录.md。
