航标选品首个公开 beta：新的独立界面，面向普通 Chrome 用户和有 agent 的用户。

- 下载 Mac 或 Windows ZIP，解压后在 Chrome 扩展管理页开启开发者模式，加载 extension 文件夹。普通用户不需要 Node、Python 或 agent。普通 ZIP 不能直接作为商店扩展安装。
- 支持多份 ABA 表、原始行与来源保留、逐词保存、异常暂停、已采集结果导出、任务备份恢复及仅续采未完成项。
- 新进度区清楚显示已采集、待采集和待重试；新增环境轮换与内存说明。
- 支持自定义 HTTP / HTTPS AI 中转站，采集任务不自动调用 AI。提供可选本机 Agent 接口及直接解析适配器。

已在 Mac 日常 Chrome 的真实 IndexedDB 验证模拟 20,000 词任务：5,000 成功后失败，导出和恢复，再仅续采剩余 15,000 个；最终保留 20,001 条原始行。此为模拟响应的断点验收，不是新版向 Amazon 实采两万词。

此版本仍是候选 beta：新扩展尚未完成真实 MV3 安装宿主、offscreen/跨域会话和 Windows 原生 Chrome 的端到端验收。代码级跨平台测试不等于浏览器安装实测。详细范围、内存限制、错误页处理和统计口径见包内 docs。
