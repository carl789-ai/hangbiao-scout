使用帮助
  1. 在 Chrome 扩展管理页开启开发者模式，选择“加载已解压的扩展程序”，选中本包 extension 文件夹。Mac 与 Windows 步骤相同。
  2. 新建任务，选择站点，导入 XLSX / CSV / TSV / TXT。重复关键词只请求一次，导出仍保留各条原始行和来源。
  3. 启动后保持 Chrome 开着、电脑联网。系统休眠、合盖、退出 Chrome 都会中断采集；重开插件后继续即可。采集期间临时阻止系统空闲休眠，屏幕可熄灭。
  4. 遇到错误页或验证页会暂停。先下载已采集结果和任务备份，在日常 Chrome 中手动检查 Amazon。网页恢复后点“继续未完成项”。
  5. 换电脑或卸载前务必备份整个任务；HTML / CSV 是查看文件，JSON 备份才能还原采集状态。
  6. Amazon 首页可打开而搜索页异常时，请直接检查暂停提示中的关键词链接。若当前网络访问失败，可手动调整网络后重试；已完成项会保留。

计算口径
单套净利润（USD）= 售价 −（采购成本＋单套头程）÷汇率 − 对应季节 FBA − 售价×佣金比例 − 售价×广告占比 − 售价×退货率。退货按销售额比例预留损耗，采购、头程、FBA、佣金与广告按全单保留，不计回收残值或佣金返还。广告占比默认 15%，退货率默认 5%，均可修改。
净利率 = 单套净利润÷售价×100%。ROI = 单套净利润÷［（采购成本＋单套头程）÷汇率］×100%；采购与头程合计为 0 时 ROI 显示 —。人民币净利润 = 美元净利润×汇率。
包装尺寸单位 cm。头程体积重：海运长×宽×高÷6000（kg），空运长×宽×高÷5000（kg）。尾程体积重：长×宽×高÷2277.8（lb），再乘 0.453592 转 kg；头程与尾程分别取各自体积重和包装实重的较大值计费。
淡季、旺季分别套用内置的美国非服装配送费表。含燃油 FBA =（表内基础费＋超重费）×1.035，按美分四舍五入；附加费按配送费计算。首批压货资金 =（采购成本＋单套头程）×首批数量。首批数量、海空运单价和目标净利率在顶部“设置”中保存。
