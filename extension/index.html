使用与安装

  1. 在 Chrome 扩展管理页开启开发者模式，选择“加载已解压的扩展程序”，选中本包 extension 文件夹。Mac 与 Windows 步骤相同。
  2. 新建任务，选择站点，导入 XLSX / CSV / TSV / TXT。重复关键词只请求一次，导出仍保留各条原始行和来源。
  3. 启动后保持 Chrome 开着、电脑联网。系统休眠、合盖、退出 Chrome 都会中断采集；重开插件后继续即可。采集期间临时阻止系统空闲休眠，屏幕可熄灭。
  4. 遇到错误页或验证页会暂停。先下载已采集结果和任务备份，在日常 Chrome 中手动检查 Amazon。网页恢复后点“继续未完成项”。
  5. 换电脑或卸载前务必备份整个任务；HTML / CSV 是查看文件，JSON 备份才能还原采集状态。
  6. 不保证每小时能采集多少词；不自动轮换 VPN、不绕过验证码、不把失败写成零值。
